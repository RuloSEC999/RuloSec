# RuloSec 🔐
### // EXPLOTA TU CONOCIMIENTO

Educational cybersecurity platform that makes web attacks visible in real time.
Plataforma educativa de ciberseguridad que hace visibles los ataques web en tiempo real.

---

## ¿Qué es RuloSec?

RuloSec es una plataforma interactiva que demuestra en tiempo real cómo funcionan
ataques como keylogging, rastreo conductual y captura de datos — en entorno 100% local,
seguro y con fines exclusivamente educativos.

## What is RuloSec?

RuloSec is an interactive platform that demonstrates in real time how attacks like
keylogging, behavioral tracking and data capture work — in a 100% local, safe environment
for educational purposes only.

---

## Stack Tecnológico / Tech Stack
- Python + Flask
- JavaScript
- HTML5 + CSS3
- REST API
- MacOS + VM Debian

## Módulos / Modules
- **Keylogger educativo** — captura pulsaciones y las explica al usuario
- **Rastreo conductual** — análisis de movimiento del ratón como vector de ataque
- **Dashboard de concientización** — visualización + guía de buenas prácticas
- **Servidor de análisis** — backend Flask que procesa datos didácticamente
